# TermLume 0.8.0

此版本将工作区扩展为通过 Aegis-IAM 授权、由 PostgreSQL 保存的个人与团队工作区。Windows 安装包统一命名为 `TermLume-0.8.0-win-x64-Setup.exe`，应用、API、桌面后端与 Electron 版本均为 0.8.0。

## 本次完成

- 按账号同步主机、分组、命令片段、收藏、最近连接与偏好，Windows 和 macOS 快捷键分别保存。
- 个人 / 共享工作区切换，所有者、管理员、编辑者、只读成员四种角色；一次性邀请、撤销邀请、移除成员、退出、转让所有权。
- 最近 50 个配置历史、预览与恢复；恢复配置时保留个人偏好、收藏和本机私钥路径。
- 持久离线队列、请求去重、版本冲突提示、明确重试或放弃，以及不含私钥路径的配置导入导出。
- 设备登记、重命名与撤销；设备凭据和 OAuth 授权均在服务端检查，工作区权限变更由桌面端定期复核。
- 可选择同步的跨设备活动日志，以及客户端不能修改或清空的服务端审计。
- 团队主机指纹参考；采用参考前需本机确认，已有信任记录冲突时拒绝覆盖。
- 数据库备份与隔离恢复工具，以及使用独立运行角色、非 root 用户和只读文件系统的 API Docker 镜像。

## 升级与本地测试

升级前备份业务数据库；003 迁移保留已有个人工作区并补齐所有者成员。保持安装产品标识和个人数据目录不变，可运行新安装包升级。旧版根目录配置需在对应账号下确认导入，并保留原文件备份。

本地测试包连接 `http://localhost:18080` 的 Aegis-IAM 公共客户端 `termlume-desktop`，通过 `http://127.0.0.1:18741` 访问工作区 API。数据库使用本机 Docker PostgreSQL 中独立的 `termlume` 库。先启动 Docker IAM，再运行 `tools/Start-WorkspaceApi.ps1`，随后打开桌面程序。

数据库密码仅保存在被忽略的服务端 `.local/` 配置中。SSH 密码、私钥口令不入库；私钥路径与已知主机信任留在本机。数据库不可用时，已有账号可在有效登录和本机缓存范围内保留待同步修改；冲突需要明确处理，工作区切换会关闭当前连接与传输。
