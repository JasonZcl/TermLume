# TermLume 0.8.1

0.8.1 是 0.8.0 的桌面安全修复版本。Windows 安装包为 `TermLume-0.8.1-win-x64-Setup.exe`；应用、共享库、桌面后端、Electron 与页面显示统一为 0.8.1，沿用原安装标识和数据目录，可直接运行新安装包升级。工作区 API 独立升级到 [0.9.0](0.9.0.md)，继续兼容此桌面端。

- 修复旧账号工作区请求延迟失败时，可能清空新账号工作区选择、影响当前界面的竞态；原生端和页面端均核验请求所属账号及工作区。
- 收紧服务器 `.local` 配置与备份目录的权限，并由初始化、备份、恢复和 Docker 配置脚本自动保护。本机已应用权限修复；服务器目录由仓库脚本管理。
- 更新 Electron 打包工具链中受影响的 minimatch 依赖，保留现有 electron-builder；该依赖不属于 Windows WPF 程序的运行依赖。
- 2026-11-20 提交前复核将自包含运行时提升到 .NET 10.0.15，并修正安装脚本对 API 版本的错误关联；版本与安装文件命名保持当前未发布基线。

本地测试仍使用 Aegis-IAM `http://localhost:18080`、公共客户端 `termlume-desktop`、回调 `http://127.0.0.1:47831/callback/` 和工作区 API `http://127.0.0.1:18741`。PostgreSQL 位于本机 Docker 的独立 `termlume` 业务库。本次无数据库结构变更；桌面程序兼容已有 0.8.0 工作区 API。

先启动本机 Docker IAM / PostgreSQL 和工作区 API，再打开应用。服务器初始化命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./tools/Start-WorkspaceApi.ps1
```

当前构建自带 .NET 10.0.15，不包含数据库密码、SSH 凭据或个人工作区。缺少 WebView2 时由微软官方引导程序联网安装。SHA-256 见安装包同目录 `.exe.sha256` 文件；此前使用 10.0.14 的本地包需要重新构建。

打包前 Release 构建为 0 警告、0 错误；198 项认证与隔离检查、32 项页面和桌面边界测试通过，npm 完整漏洞扫描为 0。包内修复页面与原生共享库均核对一致，457 个发布文件未检出本地数据库或 IAM 的实际密钥。

安全问题复现、修复和回归记录见 [首次检查](../security-review-2026-11-19.md) 和 [提交前复核](../security-review-2026-11-20.md)。PostgreSQL 功能和服务器配置见 [部署说明](../postgresql.md)。本次生成 Windows x64 安装包；未生成 macOS 安装包，也未上传 GitHub Releases。
