日志与版本回归在修复前分别复现了 503 和版本不一致，修复后均通过。日志检查同时验证 null 详情不会上传额外秘密字段，null 批次、null 条目和错误字段类型会被拒绝，见 [API 集成测试](../tests/workspace-api.integration.cjs)。

## 代码边界复核

- 登录与授权：公共客户端、S256 PKCE、state / nonce、issuer、签名、受众及令牌用途；API 同时验证 IAM 实时 UserInfo、subject、sid 和 grant。
- 数据隔离：参数化 SQL，可信身份对应的事务内 RLS 上下文；连接池限制为一条连接时验证账号切换隔离；成员角色、邀请、所有权、设备撤销、历史和审计边界。
- 桌面边界：旧账号异步回复的代次检查，敏感凭据的系统存储，页面转义，Electron 桥接操作与路径限制，SSH 主机信任和接收限额。
- 服务端边界：只开放桌面协议控制器，严格输入和正文限制，关闭框架参数审计，安全错误协议，以及 Docker 只读配置挂载。

本轮没有复现认证绕过、跨账号业务数据读取或 SQL 注入。RLS 上下文由可信 API 设置，运行角色凭据仍属于服务端秘密，不能提供给桌面用户。

在认证处理器、请求上下文、仓储事务、错误过滤及迁移器补充了边界注释，部署脚本补充用途和前置条件。已有三份 SQL 迁移未改动内容；包括注释在内的已应用迁移都受 SHA-256 校验约束。

## 同日后续验证：七天服务端日志策略

按使用要求将服务端同步活动日志及操作审计统一保留 7 天。新增 `004_log_retention.sql`，原三份迁移内容保持不变。查询与清理复用数据库中的同一截止时间规则；活动日志按接收时间，审计按生成时间计算，避免信任客户端时间。

API 启动时及每小时清理包括不活跃账号在内的过期数据。无参数的安全定义函数只删除固定期限以前的日志，不返回账号数据；PUBLIC 无执行权限，运行角色仍无审计表的 UPDATE / DELETE 权限。页面的中英文提示和部署文档已同步更新。此策略针对在线业务日志，备份与容器运行输出使用独立运维策略。
